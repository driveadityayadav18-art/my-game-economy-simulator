# Project Mission: AI-Driven Game Economy Simulator

## Vision
To build a dynamic, interactive multi-agent economic simulator where autonomous LLM-driven agents act as market participants (buying, selling, crafting, and holding). The system serves as a live testbed and interactive demo showing how macro-economic policy changes (taxes, supply drops, interest rates) impact autonomous agent behavior and emergent market stability in real time.

## Target Audience & Use Cases
1. **Hackathon Judges & AI Researchers:** Demonstrates emergent multi-agent social and economic dynamics in a visual, responsive interface.
2. **Game Designers:** Provides a playground to test and balance virtual game economies before deploying them to live multiplayer games.
3. **Educational Tools:** Gives students an intuitive dashboard to observe supply/demand shocks, hyperinflation, and policy interventions.

## Core Value Proposition
Unlike static economic simulations or single-agent tools, this project combines **LLM reasoning with persona-driven psychology** (greed, fear, risk aversion) and **real-time policy controls**, allowing users to act as a "Central Bank / Game Master" and see immediate systemic reactions.

## Project Scope
- **In Scope for MVP:**
  - 3 AI agents with distinct personas and emotional states.
  - 3 economy items ("Health Potion", "Iron Sword", "Raw Gem").
  - Automated simulation tick loop (3–5 seconds per turn).
  - Dynamic supply/demand pricing engine.
  - Policy controls (Tax Rate slider, Trigger Events like "Dragon Attack" or "Gold Rush").
  - Anomaly detection (Spike/Crash detection with AI news alerts).
  - Live dashboard with price graphs, activity log, and agent balances.
- **Out of Scope for MVP:**
  - Persistent user accounts or multi-room support.
  - Complex order book matching (using simplified algorithmic price discovery instead).
  - Fine-tuned local LLM deployment (relying on fast cloud LLM APIs).
